$ eval --help
usage: eval [-h] [--model MODEL | --config {haiku,sonnet,opus,two-stage}]
            [--prompt PROMPT] [--effort {low,medium,high,xhigh,max}]
            [--set SET_NAME | --data DATA] [--sets-dir SETS_DIR]
            [--transcribe] [--profile PROFILE] [--region REGION]
            [--bucket BUCKET] [--concurrency CONCURRENCY]
            [--reports-dir REPORTS_DIR] [--cache-dir CACHE_DIR]
            [--no-cache | --offline]

`uv run eval`: run the extractor over an evaluation set and write a report.

options:
  -h, --help            show this help message and exit
  --model MODEL         a model id (default claude-opus-5-5)
  --config {haiku,sonnet,opus,two-stage}
                        a named configuration
  --prompt PROMPT       prompt version, e.g. v1
  --effort {low,medium,high,xhigh,max}
  --set SET_NAME        a named set under eval/sets (default dev)
  --data DATA           a JSONL file of items, for ad hoc runs
  --sets-dir SETS_DIR
  --transcribe          for the audio set: transcribe each clip (cached by
                        audio hash) and score it
  --profile PROFILE     AWS profile, for --transcribe on uncached clips
  --region REGION
  --bucket BUCKET       evaluation clip bucket (default EVAL_AUDIO_BUCKET)
  --concurrency CONCURRENCY
  --reports-dir REPORTS_DIR
  --cache-dir CACHE_DIR
  --no-cache            always call the model
  --offline             answer only from the cache; fail before running if any
                        item is missing
